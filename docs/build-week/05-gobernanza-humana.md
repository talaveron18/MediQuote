# Gobernanza humana

Cada hallazgo admite una decisión: aceptado, resuelto, aplazado o bloqueado. Exige comentario, autor y fecha. Un hallazgo crítico produce `no_apto` sin ser compensado por revisores favorables.

La etiqueta de la interfaz recuerda que IA, contrato y escenarios son consultivos. Emitir, contratar, firmar o cambiar parámetros siguen siendo acciones humanas fuera de este módulo.
