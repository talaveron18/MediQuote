# Problema y oportunidad

Un presupuesto sanitario puede ser aritméticamente correcto y, aun así, fallar por contratación, cobertura, fiscalidad, convenio, protección de datos o una contradicción contractual. La oportunidad es revisar esas dimensiones antes de emitir, dejando claros hechos, supuestos, evidencias y decisiones.

La IA no calcula el precio ni aprueba. Formula preguntas, señala riesgos y explica escenarios calculados por funciones deterministas.
