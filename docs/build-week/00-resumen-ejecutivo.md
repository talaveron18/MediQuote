# MediQuote Pro — AI Review Loop

Prototipo aislado para concurso que añade una capa consultiva a MediQuote Pro sin modificar su motor determinista. Cuatro especialistas revisan la misma foto inmutable, un veredicto conjunto impide que un promedio oculte un crítico y una vista fiscal busca el peor caso razonable.

## Demostración

1. Describir un servicio en lenguaje natural.
2. Confirmar el borrador estructurado.
3. Ejecutar Gestoría, Finanzas, Auditoría y Legal.
4. Registrar una decisión humana por hallazgo.
5. Simular absentismo y generar contrato.
6. Detectar la discrepancia intencionada de precio.

El modo demo no necesita clave, no consume API y está rotulado en pantalla.
