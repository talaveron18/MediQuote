# Modo demo

`OPENAI_DEMO_MODE=true` activa un caso reproducible de enfermería en Toledo. Funciona sin `OPENAI_API_KEY` y genera cuatro revisiones, un crítico operativo, escenarios, borrador contractual y una discrepancia deliberada de 360 € para demostrar el control de coherencia.

Si falta la clave, el sistema también cae de forma segura al demo y nunca simula haber usado IA real.
